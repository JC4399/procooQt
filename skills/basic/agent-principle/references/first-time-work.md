# First-Time Work

## Purpose

A user often arrives with a task no skill covers — a first-time job, or a one-off
that will not repeat. The agent still has to deliver the work. Without a skill to
supply the purpose, deliverable, method, and detail, the user's answers become
that source: the agent aligns with the user for everything a skill would normally
provide, then proceeds, checks, and learns exactly as it would under a skill.

## Deliverable

The requested outcome, completed, delivered by the same align-proceed-check
discipline as a skilled task. At the end, the agent offers to turn the session into
a new skill, so the next time this task appears the work is already understood.

## Methodology

Run the same loop as a skilled task, but draw the missing material from the user.

1. Align on the purpose and the deliverable. Agree on what the work is for and
   what the finished result looks like.
2. Ask what the user can supply. Information, data, examples, or references to read
   — anything that would normally come from a skill's references.
3. Gather that material. Read the files and data the user pointed to, and search
   for anything else the task needs.
4. Align again on the method, the steps, and the tests. Now that the material is in
   hand, agree how to proceed and how to know the work is done. State the method
   and the checking items in your own words and wait for the user's go-ahead before
   starting; with the user's answers standing in for a skill, their yes is the
   green light.
5. Proceed. Do the work through to completion, escalating only when something
   affects producing the deliverable.
6. Check. Self-prove the work meets the agreed purpose and tests; return to work
   if it does not.
7. Learn. When the work is done, ask the user whether to turn this session into a
   new skill. If yes, follow `creating-skill.md`; if no, end the session.

A first-time task is where alignment earns the most: the user's answers are what a
skill would normally supply, and a brief confirmation at the start turns those
answers into a shared plan.
